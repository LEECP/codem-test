## 二、扩展用例（P1/P2）

### TC-12 多 Agent 共享记忆

- **前置条件**：同一机器上分别配置 Codex 与 Claude Code 接入同一 `~/.agent-memory`。
- **步骤**：Agent A 写入项目决策 → 切换 Agent B 询问该决策。
- **预期**：B 能 recall A 写入的记忆，实现"所有 AI 记得同一个你"。（PRD 2.2 场景 2、4.3）

### TC-13 对话中按需 recall

- **前置条件**：历史记忆存在。
- **步骤**：对话中提及过去话题（非任务开始）。
- **预期**：Agent 自动 recall 相关历史信息。（PRD 3.2.5 召回时机）

### TC-14 需确认写入模式

- **前置条件**：初始化时记忆模式选"需确认写入"。
- **步骤**：触发记忆写入。
- **预期**：写入前需用户确认；拒绝则不写入。（PRD 3.2.2 步骤 5）

### TC-15 语义检索（可选 embedding）

- **前置条件**：`enable-embedding` 已启用并配置 provider。
- **步骤**：用语义相近但字面不同的查询做检索。
- **预期**：能召回语义相关记忆；延迟 < 2s；禁用 embedding 时功能完整不受影响。（PRD 3.2.5、1.2）

### TC-16 存储位置自定义

- **前置条件**：init 向导第 1 步。
- **步骤**：指定非默认存储路径。
- **预期**：所有数据（db、summaries、indexes、logs）落入自定义路径，status 正确展示。（PRD 3.2.2）

### TC-17 Global/Project 记忆隔离

- **步骤**：在项目 A 中检索，构造仅存在于项目 B 的记忆关键词。
- **预期**：项目 B 的 Project 记忆不被项目 A 召回；Global 记忆两边均可见。（PRD 5.2）

### TC-18 记忆导出与迁移

- **步骤**：`agent-memory export` 导出 → 在另一环境导入。
- **预期**：数据完整可迁移，检索功能正常。（PRD 5.4，P2）

### TC-19 doctor 诊断

- **步骤**：人为制造异常（删除 db 文件、损坏 config）后执行 `agent-memory doctor`。
- **预期**：能定位常见问题并给出修复建议，不静默失败。（PRD 5.4）

### TC-20 多 Agent 并发写入一致性

- **步骤**：两个 Agent 同时写入记忆。
- **预期**：SQLite 事务/写入锁保证数据一致，无丢失或损坏。（PRD 8.1 风险）

### TC-21 兼容性矩阵

- **步骤**：在 macOS / Linux / Windows(WSL) 上安装运行；分别以 Skill / MCP / CLI 方式接入。
- **预期**：PRD 5.3 兼容性矩阵全覆盖，最低依赖、无需 Docker。

### TC-22 存储空间占用

- **步骤**：正常使用（模拟 1 年量级写入）后检查目录体积。
- **预期**：存储空间 < 1GB/年；归档机制正常工作。（PRD 5.1、4.2）
